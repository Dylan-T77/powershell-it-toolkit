# PowerShell IT Toolkit

**Status:** Planned

A practical collection of PowerShell tools for IT administration, diagnostics and automation.

## Objectives
- Build reusable administration scripts
- Automate repetitive support tasks
- Learn robust PowerShell patterns and error handling
- Query systems, services, users, networking and logs
- Document scripts so they can be understood and maintained

## Planned Structure
```text
powershell-it-toolkit/
├── README.md
├── scripts/
│   ├── system/
│   ├── networking/
│   ├── users/
│   ├── services/
│   └── diagnostics/
├── docs/
├── reference/
└── tests/
```
